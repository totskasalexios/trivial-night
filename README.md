# Music (optional)

Drop mp3 files in this folder to give the board a music bed. Nothing here is
required — with the folder empty the game runs silent apart from its effects.

| File           | Plays over                    |
|----------------|-------------------------------|
| `lobby.mp3`    | players joining               |
| `question.mp3` | the questions                 |
| `scores.mp3`   | the scoreboard between rounds |

Each track loops at low volume and is cut when the board moves on. A file that
is missing is skipped silently, so you can add one, two or all three.

Use music you are allowed to use. If the game is played in public or the repo
is public, that means properly licensed or public-domain tracks.
